# 🍕 Pizza Order System

A full-stack Pizza Ordering System developed using React.js, Spring Boot, and PostgreSQL.

## 🛠️ Technologies Used

- React.js
- JavaScript
- HTML
- CSS
- Axios
- Spring Boot
- Java
- Spring Data JPA
- REST API
- PostgreSQL
- Maven
- Git & GitHub

## 👤 Customer Features

- Register and Login
- View available pizzas
- Add pizza to cart
- Place orders
- View order history
- Track order status

## 👨‍💼 Admin Features

- Admin Login
- Manage Pizzas
- Add, Edit and Delete Pizzas
- Manage Customers
- Activate and Deactivate Customers
- Manage Orders
- Update Order Status
- Manage Payments
- Confirm Payments

## 🏗️ System Architecture

React.js → REST API → Spring Boot → PostgreSQL
